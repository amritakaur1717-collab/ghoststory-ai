# 👻 GhostStory AI

A spooky story generator website inspired by haunted houses, mysterious forests, glowing pumpkins, and supernatural adventures.

## ✨ Features
- Generate spooky sample stories from a user's topic
- Choose between Spooky, Mysterious, and Supernatural moods
- Dark, Halloween-inspired design
- Simple and beginner-friendly interface

## 🛠️ Built With
- HTML
- CSS
- JavaScript

## 🚀 How to Use
1. Open the website.
2. Enter a story idea.
3. Choose a mood.
4. Click "Create My Story".

## 📝 Note
This is a beginner project that currently uses predefined story templates. It is not connected to a real AI model yet.
